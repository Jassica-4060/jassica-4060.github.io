| 組別 | 製作內容 |

**內容順序：**

**注意：** 無資料時不自行生成設計理念。草稿或提案比較不是必要內容，有素材再增補。

**已確認形式：** 只放活動照片搭配簡短說明。本區不安排成果數據卡、成效分析或設計稿對照。

**建議照片位置與圖說占位：**

| 照片位置 | 圖說占位方向，依實際照片調整 |

| 拍照區 | 拍照背板於現場的實際應用 |
| 流程看板／電子看板 | 活動資訊在會場中的呈現 |
| 產品體驗區 | 體驗展場背板與現場空間的搭配 |
| 其他現場細節，選填 | 名牌、桌牌或印刷素材的使用情境 |

以上是選圖方向，不代表已提供這些照片。照片不足時可減少張數。圖說先保留待補，不自行描述來賓反應或活動成效。
