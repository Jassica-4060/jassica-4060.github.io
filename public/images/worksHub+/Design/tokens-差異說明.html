Design Token v2(圓角版)差異說明

來源：WorksHub-圓角版.html ・ 對照基準：線上 dev 後台 index-Dnj-hRg-.css(與 v1 tokens.json 完全一致)・ 2026-10-02 ・ Jessica Huang

新檔 tokens.json 沿用 v1 結構，可直接取代。主要變動：品牌藍換色、中性色整套重做、控制元件改膠囊圓角、移除紫色、版面改成浮起卡片。

改值 新增 移除 設計決議

1. 會造成程式破壞的變動(請先處理)

  • 移除 取消主題色切換,只保留淺色 / 深色兩種模式。themes(blue / green / purple)整組移除，改為單一的 accent.light / accent.dark。前端的主題清單 ['blue','green','purple']、NaiveUI 各主題的 themeOverrides、header 的「主題色」按鈕都可以拿掉；使用者已存的主題偏好可直接忽略。
  • 改值 radius.sm / md 由 2px / 3px 改為 9999px。NaiveUI 的 common.borderRadius 會影響 Card、Modal、Dialog、Popover、Dropdown、Tag,以及彈窗內的 Input / Select,請在 themeOverrides 或元件層另外覆寫(見第 4 節)。
  • 新增 主要按鈕專用色 button.primary-bg(#2B7BC9),比主色深一階。請用 NaiveUI Button 的 themeOverrides 覆寫，不要改 common.primaryColor(否則選單選中、勾選框、開關、連結也會跟著變)。
  • 新增 $type: "shadow" 與 "gradient",$value 為 CSS 字串，tokens:build 腳本需支援輸出。

5. 版面、陰影、漸層與其他視覺差異

  • 版面結構:header(68px)橫跨整排、沒有底線；下方側欄與主內容各自是浮起的圓角卡片，間距與外距 16px。側欄寬 220 → 240px,收合 64px。
  • 選單選中態:v1 左側 3px 色條 → v2 整塊主色底 + 白字 + shadow.accent 光暈；子項選中改青綠底。分組標題前加 6px 青綠小方塊。
  • Header:收合／深淺色 icon 按鈕包成一個群組框(設計稿的「主題色」按鈕因取消主題切換而移除);日期與使用者區塊改成獨立的膠囊框，頭像用 gradient.brand。
  • 麵包屑:改成 26px 高的膠囊(subtle-bg)。
  • 空狀態:白卡陰影 → section-bg 底 + 1.5px 虛線框(section-border),icon 用品牌漸層。
  • 表格:表頭不再有底色，改純文字 + 細線；操作欄按鈕有 secondary-bg 底，hover 時編輯變主色、刪除變 danger。
  • 彈窗:遮罩加 backdrop-filter: blur(3px),標題前加漸層 icon,關閉鈕為圓形。
  • 控制元件高度 新增:按鈕 42px(size.button-height)、篩選下拉 40px(size.input-height-filter)、彈窗輸入框 46px(size.input-height-modal),兩種輸入框刻意不同高。
  • 不變:chart 色盤、9 個訊息分類色(含影片紫色)、字級 text-2xs、min-width 1280、avatar-lg 64。

6. 設計決議紀錄(2026-10-02 拍板，目前沒有待確認項目)

  • 取消主題色切換，只保留淺色 / 深色兩種模式；header 的「主題色」按鈕移除。
  • 訊息分類色「影片」保留紫色 violet-500。
  • 彈窗輸入框 12px、角色標籤 8px、表格操作按鈕 10px、header icon 按鈕 8px、彈窗關閉鈕正圓，皆照設計稿保留。
  • Dropdown / Popover 等浮出框用 12px 圓角。
  • 按鈕與輸入框高度不需統一：按鈕 42px、篩選下拉 40px、彈窗輸入框 46px。
  • 只有主要按鈕加深成 #2B7BC9(白字對比 3.57 → 4.39),hover #266CB1、按下 #215F9C;選單選中、勾選框、開關、連結維持主色 #348BDD。
